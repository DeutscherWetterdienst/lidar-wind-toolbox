Important boundaries

Filesystem and content handling

hpl_files discovers and sorts paths. The legacy boundary then reads each path into bytes. Halo and WindCube adapters parse those bytes; they do not own directory discovery.

Normalized versus native WindCube data

Halo and WindCube radial inputs become NormalizedRadialData and are rebuilt into the normalized Level-1 schema. The regular WindCube native scan branch returns native variables and follows a separate normalization path.

Daily and NRT processing

Daily processing expands the discovered file list with nearby files from the previous and following date boundaries. NRT processing uses a time window and may remove the temporary Level-1 product after Level-2 processing.

Stare workflow

The stare commands combine stare Level-1 data with a wind Level-2 product, then write stare Level-2 output and optional epsilon, atmospheric-variance, and wind-mean quicklooks.
